## 1. 개요 및 배경

애드센스 수익을 극대화하려면 단순히 1개 글의 유입으로 끝나는 것이 아니라, 독자가 블로그 내 다른 고수익 글(법률, 보험, 금융 등)로 계속 이동하는 **내부 링크 체인(Topic Cluster / Silo Structure)**이 구축되어야 합니다.

1. **체류 시간 및 PV 증대**: 내부 링크를 통해 페이지뷰가 2~3배 증가하고 반송률(Bounce Rate)이 급감합니다.
2. **구글 SEO 가중치 상승**: 검색엔진 크롤러가 블로그 내 전문 분야의 토픽 클러스터를 인식하여 검색 노출 순위를 끌어올립니다.
3. **고수익 전환 유도**: "교통사고 합의" 글에서 "운전자보험 청구 팁"이나 "변호사 상담 가이드" 글로 자연스럽게 연결되어 고단가 광고 클릭 기회를 확대합니다.

## 3. 내부 링크 모듈 상세 설계 (`app/content/internal_links.py`)

### 3.1 동작 알고리즘
1. **입력 파라미터**:
   - `session`: SQLAlchemy DB 세션
   - `category`: 현재 글의 카테고리
   - `exclude_title`: 현재 글의 제목 (자기 자신 링크 제외용)
   - `limit`: 추천 링크 최대 개수 (기본 3개)
2. **DB 조회 대상**:
   - `PublishJob.status == PublishStatus.VERIFIED`이고 `result_url`이 존재하는 실제 발행 글
   - 최신 발행순 정렬
3. **우선순위 로직**:
   - 1순위: 동일 카테고리 글 최신순 최대 `limit`개
   - 2순위: 동일 카테고리 글이 부족할 경우, 다른 고수익 카테고리의 최신 글 보충 (합계 최대 `limit`개)
4. **렌더링 포맷**:
   ```html
   <blockquote>
     <strong>📌 함께 읽으면 돈이 되는 관련 추천 가이드</strong>
     <ul>
       <li><a href="https://lmh-life.tistory.com/123">교통사고 형사합의 절차 및 판례 가이드</a></li>
       <li><a href="https://lmh-life.tistory.com/124">실손보험 도수치료 청구 거절 시 금감원 민원 대처법</a></li>
     </ul>
   </blockquote>
   ```
5. **안전성 및 예외 처리**:
   - 기발행 글이 0개이거나 오류 발생 시 원본 본문 그대로 반환 (포스팅 중단 없음).
   - XSS 방지를 위해 제목과 URL 모두 `html.escape` 처리.

## 4. 애드센스 스킨 배치 가이드 설계 (`docs/adsense_placement_and_skin_guide.md`)

1. **상단 2개 분할 배치 (데스크톱) / 상단 대형 배너 (모바일)**:
   - 첫 진입 시 가장 시선이 머무는 곳에 고단가 반응형 디스플레이 광고 노출.
2. **첫 번째 `<h2>` 바로 위 인라인 광고**:
   - 검색 유입자가 첫 번째 솔루션 섹션으로 스크롤하기 직전 노출 (CTR 최대 지점).
3. **본문 내 강조 `<blockquote>` 박스 상/하단 연계**:
   - 정부 지원금 조회, 무료 상담, 절세 계산기 안내 박스 전후로 인피드/일치하는 콘텐츠 광고 연계.
4. **사이드바 Sticky 고정 배너 (CSS `position: sticky`)**:
   - 긴 스크롤 체류 중 항상 우측에 고수익 광고 유지.
5. **하단 내부 링크 블록 직전 멀티플렉스(일치하는 콘텐츠) 광고**:
   - 추천 글 목록 직전에 관련 광고를 자연스럽게 융합하여 이탈 방지 및 추가 클릭 유도.
