## 1. 기존 썸네일 디자인 스타일 분석 (디자인 시스템 정의)

1. **화면 비율**: `16:9` 와이드 (고해상도 블로그 배너 및 썸네일 규격)
2. **좌측 레이아웃 (한글 인포그래픽 타이포)**:
   - 상단: `💡 꼭 알아야 할` 캡슐 뱃지
   - 메인 헤드라인: 굵고 또렷한 대형 한글 텍스트 (`[카테고리명] 총정리`)
   - 서브 뱃지: 라운드 컬러 캡슐 바 (`[핵심 요약 행동 문구]`)
   - 하단: 체크마크 3단 체크리스트 (`✔ [핵심 포인트 1, 2, 3]`)
3. **우측 레이아웃 (3D 스튜디오 소품 & 대시보드)**:
   - 전면에 세련된 모니터/태블릿 (주제별 한국어 웹 대시보드 화면)
   - 책상 위 현실적인 3D 오브젝트 배치 (계산기, 서류 클립보드, 달력, 도장, 핵심 상징물)
4. **색감 및 배경**:
   - 깔끔한 화이트/소프트 그레이 스튜디오 배경
   - 카테고리별 테마 컬러 (블루, 네이비, 청록, 오렌지 등)
